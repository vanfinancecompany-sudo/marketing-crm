# Rent2Buy Buffer 10-Reel proof

This is a temporary controlled proof before permanent Facebook automation is enabled.

- Replaces the old one-Reel proof button with one explicit 10-Reel Rent2Buy batch button.
- Requires the unlocked Marketing CRM browser session and a confirmation dialog.
- Builds ten real Rent2Buy MP4 Reels from live Wix vehicle image feeds.
- Uses four rotating Rent2Buy message packs.
- Sends only to the RENT to BUY VANS Buffer channel as queued Reels.
- Does not create Finance posts or touch Marketplace.
- Does not alter the Daily Reels 10 + 10 counters or 48-hour history.
- No instant shareNow publishing route is added.
- If fewer than ten eligible vehicles exist, nothing is queued.
- If a partial runtime failure occurs after some Reels queue, the button stays disabled to avoid duplicate retries.

Remove this temporary proof control after the batch has been verified in Buffer/Facebook and before final automation cleanup.
