# Buffer Facebook Architecture

```text
Marketing CRM
  -> server route /api/buffer-publishing
  -> Buffer GraphQL API
  -> Van Finance Company / RENT to BUY VANS Facebook Pages
```

Static Facebook posts reuse the vehicle image URL already held by the CRM. Daily Reels reuse the public Vercel Blob MP4 URL already generated by the reel renderer. The Buffer bearer key never reaches browser code.

During the proof stage every mutation is forced to `saveToDraft: true`. Draft creation does not write a confirmed Facebook posting event to the Marketing CRM.
