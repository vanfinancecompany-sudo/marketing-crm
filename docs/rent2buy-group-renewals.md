# Rent2Buy Facebook group renewals (every 7 days)

For existing Proven/Hot Rent2Buy group adverts. Discovery and joining remain manual.

- **Daily queue (07:00 UTC cron, `GET /api/rent2buy-group-renewals?run=1`):** once per London day (the `run_date` primary key blocks duplicate runs). It takes due Proven/Hot Rent2Buy groups using the CRM's own `groupPipeline` + `groupDueState` (the same as the Facebook Groups page), up to the CRM daily limit, with a maximum of 30. It runs only when enabled in the CRM and only in production.
- **Stale records never exclude a proven group.** Unresolved previous posts, membership, permission, unavailable or Red flags are shown as checks on the group. Clean groups are queued first.
- **Automatic renewals.** Enable the daily queue in Conversations & AI, then select **Enable automatic renewals** in Rent2Buy Facebook Groups with the Groups Helper installed in the intended Edge profile. Keep Edge signed in to the CRM and Facebook. Each renewal uses the existing rotation, caption and photo. The helper verifies the Facebook draft and reserves the submission before using the native Post action once. It reuses the Facebook tab and spaces submissions by at least a minute. Each day it resumes from the CRM queue without a click or refresh.
- **Exceptions.** A group with an unresolved prior submission is held for review. A group-specific failure is flagged and the queue continues. The helper stops the current run on Facebook sign-in, account or security restrictions. Missing or ambiguous publication confirmation is flagged and held across future runs. If a held advert needs reconciling, check Facebook for the previous advert before using the existing manual group controls.
- **Reporting.** Conversations & AI shows the queue, confirmed submissions, acceptance results and exceptions. A confirmed submission resets the seven-day countdown. The existing acceptance monitor checks for evidence of the specific renewed advert, up to three times.
- **Eligibility.** Automatic processing requires a previously accepted advert and stops on group rules that prohibit the advert or its link. The helper uses the signed-in browser and group composer. Meta withdrew the Groups API in 2024.
- **Verification before rollout.** Use the verified renewal branch Preview alias with the existing migration `202611251610_rent2buy_group_renewal_runs.sql` applied to its test database and Groups Helper 1.2.30 installed in a test profile. The scheduler is production-only. Validate preparation and duplicate protection, then verify an approved live submission and its acceptance signal before enabling the live queue.
