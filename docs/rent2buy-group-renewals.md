# Rent2Buy Facebook group renewals (every 7 days)

Publishes a new vehicle advert to each due Proven/Hot Rent2Buy group. Discovery and joining remain manual.

- **Hourly checks.** The production cron at `GET /api/rent2buy-group-renewals?run=1` appends newly due Proven/Hot groups using the Rent2Buy Groups eligibility rules. The London-day record preserves claims, reviews and outcomes and limits the day to the configured maximum of 30 or fewer groups.
- **Eligibility.** Previous acceptance and the interval since the last submission determine when a new advert is due. Historical approval or search results do not gate a new cycle. Membership, posting permission and group rules are checked before posting.
- **Automatic adverts.** Enable hourly checks in Conversations & AI, then select **Pair background Groups Helper** in Rent2Buy Facebook Groups to connect the existing Edge profile. Pairing preserves the saved enabled or paused setting. The service worker uses the existing rotation, caption and photo, validates the Facebook draft, and reserves one native Post action. It leaves 60–90 seconds between submission attempts. Keep Edge running with Facebook signed in. Adverts are prepared in a dedicated Facebook window that the helper opens without taking focus; leave it open (it may sit behind other windows) but do not minimise it, because Facebook only renders the composer in a visible page. A hidden page stops that advert with a clear reason and nothing is posted. The desktop CRM and CRM webpages can be closed.
- **Exceptions.** A recent interrupted or uncertain submission holds that group for one full configured interval from the attempt unless it is reconciled sooner. The helper can review those attempts after taking care of eligible groups. A clear Facebook failure is recorded separately. Group-specific issues leave other eligible groups available, and Facebook sign-in or security restrictions stop the run.
- **Reporting.** Confirmed manual and automatic adverts count once in the Rent2Buy Groups Content Operations total. Conversations & AI tracks agent health, run counts and per-advert history. The acceptance monitor checks the specific renewed advert up to three times. A confirmed submission resets the seven-day countdown.
- **Alerts and access.** The extension worker reports every five minutes when Edge is running and the device is awake. The worker credential allows only the Rent2Buy group actions and can be revoked under Rent2Buy Facebook Groups. The hourly approval alarm and five-minute renewal alarm are restored if missing.
- **Eligibility.** Automatic processing requires a previously accepted advert and stops on group rules that prohibit the advert or its link. The helper uses the signed-in browser and group composer. Meta withdrew the Groups API in 2024.
- **Rollout verification.** Apply the background worker database migration, deploy the CRM, and reload Groups Helper v1.2.40 in the existing Edge profile. Pair once and check worker heartbeats, hourly scans, and approval alarms. The one-use Southampton control requires eligibility and an available queue entry. A verified Facebook submission must produce one activity record, reset the group's interval, and enter separate approval tracking.
