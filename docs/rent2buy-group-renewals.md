# Rent2Buy Facebook group renewals (every 7 days)

For existing Proven/Hot Rent2Buy group adverts. Discovery and joining remain manual.

- **Hourly checks.** The production cron at `GET /api/rent2buy-group-renewals?run=1` appends newly due Proven/Hot groups using the Rent2Buy Groups eligibility rules. The London-day record preserves claims, reviews and outcomes and limits the day to the configured maximum of 30 or fewer groups.
- **Stale records never exclude a proven group.** Unresolved previous posts, membership, permission, unavailable or Red flags are shown as checks on the group. Clean groups are queued first.
- **Automatic renewals.** Enable hourly checks in Conversations & AI, then select **Enable automatic renewals** in Rent2Buy Facebook Groups with the Groups Helper installed in the intended Edge profile. Keep Edge signed in to the CRM and Facebook. Each renewal uses the existing rotation, caption and photo. The helper validates the Facebook draft and reserves the submission before using the native Post action once. It leaves 60-90 seconds between submission attempts.
- **Exceptions.** The helper checks held adverts by their verified Facebook permalink, or an exact registration, group, date and Rent2Buy link when a permalink was never saved. A single confirmed match records acceptance, pending approval or rejection. A missing or ambiguous result keeps the duplicate hold. Explicit Facebook failure with the original composer still open is recorded as a failure. Group-specific issues leave other eligible groups available, and Facebook sign-in or security restrictions stop the run.
- **Reporting.** Confirmed manual and automatic adverts count once in the Rent2Buy Groups Content Operations total. Conversations & AI tracks agent health, run counts and per-advert history. The acceptance monitor checks the specific renewed advert up to three times. A confirmed submission resets the seven-day countdown.
- **Alerts.** The extension worker reports every five minutes even when the queue is empty or the CRM tab is inactive. Its credential can report only a heartbeat. Edge must be running and the device awake for browser alarms to fire. The hourly approval alarm and five-minute renewal alarm are restored if missing.
- **Eligibility.** Automatic processing requires a previously accepted advert and stops on group rules that prohibit the advert or its link. The helper uses the signed-in browser and group composer. Meta withdrew the Groups API in 2024.
- **Rollout verification.** Deploy the CRM and update the installed Groups Helper to 1.2.33 in the signed-in Edge profile. When work is ready, the helper wakes its existing driver or reopens it and uses the single-tab safety lock to restore ownership. Check for consecutive extension-worker heartbeats with an empty queue, an hourly cron receipt, an hourly approval alarm receipt and a real Facebook result when a group becomes eligible.
