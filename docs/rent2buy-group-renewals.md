# Rent2Buy Facebook group renewals (every 7 days)

For existing Proven/Hot Rent2Buy group adverts. Discovery and joining remain manual.

- **Daily queue (07:00 UTC cron, `GET /api/rent2buy-group-renewals?run=1`):** once per London day (the `run_date` primary key blocks duplicate runs). It takes due Proven/Hot Rent2Buy groups using the CRM's own `groupPipeline` + `groupDueState` (the same as the Facebook Groups page), up to the CRM daily limit, with a maximum of 30. It runs only when enabled in the CRM and only in production.
- **Stale records never exclude a proven group.** Unresolved previous posts, membership, permission, unavailable or Red flags are shown as checks on the group. Clean groups are queued first.
- **Automatic renewals.** Enable the daily queue in Conversations & AI, then select **Enable automatic renewals** in Rent2Buy Facebook Groups with the Groups Helper installed in the intended Edge profile. Keep Edge signed in to the CRM and Facebook. Each renewal uses the existing rotation, caption and photo. The helper verifies the Facebook draft and reserves the submission before using the native Post action once. It reuses the Facebook tab and spaces submissions by at least a minute. Each day it resumes from the CRM queue without a click or refresh.
- **Exceptions.** The helper checks held adverts by their verified Facebook permalink, or an exact registration, group, date and Rent2Buy link when a permalink was never saved. A single confirmed match records acceptance, pending approval or rejection. A missing or ambiguous result keeps the duplicate hold. Explicit Facebook failure with the original composer still open is recorded as a failure. Group-specific issues leave other eligible groups available, and Facebook sign-in or security restrictions stop the run.
- **Reporting.** Confirmed manual and automatic adverts count once in the Rent2Buy Groups Content Operations total. Conversations & AI tracks agent health, run counts and per-advert history. The acceptance monitor checks the specific renewed advert up to three times. A confirmed submission resets the seven-day countdown.
- **Alerts.** The Edge driver reports every five minutes. The dashboard shows publication exceptions even after the short alert window has passed. It also distinguishes confirmed outcomes, a run with nothing due, a stalled browser and an intentional pause. Critical renewal incidents use the existing alert email settings.
- **Eligibility.** Automatic processing requires a previously accepted advert and stops on group rules that prohibit the advert or its link. The helper uses the signed-in browser and group composer. Meta withdrew the Groups API in 2024.
- **Verification before rollout.** The repair uses the existing queue and monitoring migrations. Deploy the CRM and reload Groups Helper 1.2.32 in the signed-in Edge profile. Verify that the open Rent2Buy Groups tab owns the CRM safety lock, automatic renewals are enabled, and the helper reports a current execution receipt. The scheduler runs only in production. Verify a genuine Facebook outcome from an authorized run before declaring production delivery healthy.
